# Data Engineering Bootcamp (dataexpert.io)

Welcome to my project repository for the 6-week Data Engineering Bootcamp with dataexpert.io. Throughout the program, I worked on and refined several code examples, which I’ll be sharing here.

## 📌 Week 1: Dimensional Data Modeling

- Introduces modeling using complex types and maintains complete historical records through cumulative table strategies.
- Focuses on managing dimension changes over time with SCD Type 2 implementations and building robust, idempotent data pipelines.
- Enhances understanding of aggregation patterns through additive vs non‑additive dimensions, enum usage for clean categorical data, and graphs for relationship modeling.

## 📌 Week 2: Fact Data Modeling
- Lays the groundwork by defining facts, addressing scale, deduplication, and retention concerns, then grounding theory in a real-world NBA dataset.
- Progresses into metric-driven modeling, demonstrating compression strategies such as datelist integers and emphasizing sampling approaches when full precision is unnecessary.
- Focuses on balancing compact modeling with flexible querying, teaching how to build and interpret compressed fact structures to support efficient analytics pipelines.

## 📌 Week 3: Spark Fundamentals
- Introduces Spark’s core architecture: DAG planning, memory management, and join strategies—grounded in a lab showcasing broadcast/hybrid join optimizations.
- Emphasizes management of Spark notebooks and production pipelines: caching strategies, CI/CD integration, automated testing, and performance tuning.
- Centers on scalable batch pipeline engineering: partitioned workflows, file format optimizations, shuffle reduction, and resource tuning in real-world settings.
